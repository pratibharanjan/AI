# Dataset folder

Download a real retail/superstore Excel workbook and place it here if you want to keep a local copy.
You can also upload the workbook directly through the Streamlit app.

Preferred fields: Order ID, Order Date, Product Name, Category, Quantity, Sales, Profit, Region.
The application supports flexible column mapping, so exact header names are not mandatory.

The `dataset_template.csv` in Phase 1 is illustrative only. Do not use it to make real business claims.
